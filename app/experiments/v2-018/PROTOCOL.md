The second arm adds only four features: 14-day mean forecast error and mean absolute error for v2 and pinned ECMWF day2. Error means forecast minus observed radiation. Divide all four features by 100. Do not refit the base or change the head configuration.

The source histories are frozen 016 OOF forecasts followed by its fixed validation curve. No predictions from a model trained on its own future labels may enter history. Preserve source checks and both history counts/latest admitted target times for every row. Coverage is diagnostic, not an additional predictor. The two error features for a source are zero when that source has no usable observations. Partial windows use their available observations.

Observed radiation comes from the pinned upstream weather table. Separate observations used for training contexts from the later validation observation stream. Training error features are computed at each training origin with the same strict window. Existing head folds three through six retain the strict target-before-held-origin fit purge. Save every intermediate head, membership and probability.

Required preflight checks include strict 336h boundary inclusion, exact-origin exclusion, zero-history behavior, both history counts, v2 source-origin identity, and prefix invariance: changing any observation at or after an origin must leave its features and resulting fixed-model decision unchanged.

[Schulz et al.2021](https://arxiv.org/pdf/2101.06717), §3.3, PDF pp.9–10, discusses rolling versus expanding past-data post-processing and changing weather/model conditions. Here rolling error context is a fixed engineering extension, not its EMOS implementation or a guaranteed adaptation method. Observed validation has already informed prior research. Archived NWP operational publication times remain unverified, and the historical v2 forecast sequence is reconstructed OOF history, not a logged live forecast feed.
