Sources and limits

V2 + event correction

The default uses the independently audited v2-019/expanded event calls. A small logistic correction combines the V2 prediction, three weather forecasts, solar timing and strictly past forecast errors. Its 0.49 probability cutoff was fixed using chronological training predictions.

The plotted V2 refit is the exact frozen radiation curve used by that correction. It retains Stefanos’s model configuration, with tree count selected on training data. It is a separate refit from his supplied CSV. Its MAE is 18.700675 W/m². The event correction does not alter this curve.

Against 008, validation F1 rises by 0.4269 percentage points with four fewer false alarms and one additional missed hour. The paired-day 95% interval for the F1 difference spans −1.6061 to +2.6215 points. That does not establish superiority on new data. Past-error features use only observations available before each forecast origin. This is a historical sequential simulation.

Original v2

Selecting either original v2 option restores the retained predicted column from cv_predictions_v2.csv. Its MAE is 18.697343 W/m². Threshold 562 changes event calls only. The cloud readout comes from nwp_cloud in the same source snapshot’s featuresv2.csv, joined by validation origin.

No v2 test predictions were supplied in this snapshot. No new fitting happens in this view. These validation hours have been inspected repeatedly.

Two weather sources

Supplied weather, day 1 is the v2 CSV’s forecast column. Its downloader requests previous_day1 from Open-Meteo without pinning a weather model.

ECMWF, day 2 is a separate retained archive pinned to ecmwf_ifs025, using shortwave_radiation_previous_day2. It is not the weather column supplied with v2.

Day 1 and day 2 are nominal provider offsets. Historical publication timing and original forecast availability remain unverified.

Reference and event model

“Actual” is the retained historical weather radiation reference. A radiation threshold is not a measurement of curtailed solar power or a water-saving result.

The two-source event comparator is f1-008/consensus_two_source, with its retained 0.50/0.60 correction rule. It supplies yes/no event calls, not a radiation forecast. When selected, the chart keeps the V2 refit explicitly as a reference. Its rule was selected on validation.

Time and coverage

CSV feature timestamps are shifted forward 24 hours to their target. The recovered source clock is fixed UTC+03:00, without a seasonal clock change. Radiation is the preceding-hour mean at each target label.

The schedule page retains its original supplied plan and costs. These v2 predictions do not replace that plan’s input.
