\titleline{01 / SOLUTION DESCRIPTION}{Schedule around storage.}
Use electricity that would otherwise be curtailed to produce drinking water. Store water for evening demand. This requires spare production capacity, usable tank storage and coordination with the grid operator.

\smallhead{Current implementation}
Historical Paphos weather feeds a LightGBM radiation reference. A constrained scheduler plans one unit and one tank. The workspace connects assets, plans, evaluation, grid evidence and review records. Pilot inputs checks declared observation files, units, gaps and first-available times separately from planning. Streamlit retains the local experiment. No controller or live plant is connected.

\smallhead{The water balance}
\[
S_{h+1}=S_h+q_h-d_h,\qquad S_{\min}\le S_h\le S_{\max},\qquad 0\le q_h\le q_{\max}.
\]
$S$ is stored water, $q$ production and $d$ demand. The current solver minimises the assumed tariff cost; forecast sunshine breaks ties between equally priced hours. Both schedules finish with the same water and storage. Ramp rates, maintenance and minimum run times need operator data.

\smallhead{Why test machine learning}
Weather changes the useful production windows. Machine learning combines weather and calendar signals to test whether that timing can be anticipated. Superiority is unproven: the current reference loses on MAE and adds no tariff saving over price-only scheduling. Retain AI only if a new pilot beats competent controls on matched water service, cost or measured renewable absorption. Sunshine itself is not a curtailment measurement.

During that window, planned load is 5,117 kWh; flat load is 1,734 kWh. The price-only control also gives 5,117 kWh. This is timing overlap, not recovered solar energy. The grid report never enters the scheduler. Across 62 reported days and five tank sizes, 310 matched cases were checked; September coverage is unknown.

\smallhead{Forecast control}
The independent reference is not Stefanos's model. Training ends before July; July--September contains 2,208 hours. MAE: 8.812 model / 7.638 safe persistence. RMSE: 17.942 / 19.433 W/m\textsuperscript{2}. Issue time is previous-day 18:00; persistence uses yesterday through hour 18 and two days earlier after that. The $600\ \mathrm{W/m^2}$ threshold was selected in June.

\smallhead{Checks and limits}
Reconstruction weather is not sensor truth or an archived issued forecast. EAC's Group 1 fields are not national totals. Published percentages are retained; 11 daily reports have arithmetic discrepancies beyond displayed rounding. The synthetic garden and leak checks are demonstrations, not field validation.
