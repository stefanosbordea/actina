# Aktina

Turn daytime solar availability into stored water through desalination scheduling.

- **Model and scheduler:** `model/`, by Stefanos.
- **Predictions and schedule:** `eval/`.
- **Website, review tools and delivery sources:** [`app/`](app/README.md), by Loukas Louka.

The website integrates the supplied historical data with illustrative plant, demand and price assumptions. It does not control a plant or establish measured savings.
